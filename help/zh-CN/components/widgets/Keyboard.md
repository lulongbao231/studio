# DESCRIPTION

用于向文本区域写入文本的虚拟（屏幕）键盘。

[更多信息](https://docs.lvgl.io/8.3/widgets/extra/keyboard.html)

# PROPERTIES

## Textarea

连接到这个 Widget 的 `Textarea` Widget 的名称。

## Mode

可用的模式如下：

-   `TEXT_LOWER` – 显示小写字母。
-   `TEXT_UPPER` – 显示大写字母。
-   `SPECIAL` – 显示特殊字符。
-   `NUMBER` – 显示数字、+/- 符号和小数点。
-   `USER_1` 到 `USER_4` – 用户自定义的模式。
