# DESCRIPTION

此 Widget 允许用户选择一种颜色。

[更多信息](https://docs.lvgl.io/8.3/widgets/extra/colorwheel.html)

# PROPERTIES

## Mode

选择通过 Widget 改变颜色的哪个部分：

-   `HUE`（色相）
-   `SATURATION`（饱和度）
-   `VALUE`（明度）

## Fixed mode

使用此选项可以固定颜色模式（以便在长按时不改变）。

## Knob recolor

选择旋钮背景的颜色。
