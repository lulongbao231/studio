# DESCRIPTION

此 Widget 用于显示日历。

[更多信息](https://docs.lvgl.io/8.3/widgets/extra/calendar.html)

# PROPERTIES

## Year

初始选中的年份。

## Month

初始选中的月份。

## Day

初始选中的日。

## Header

日历的头部类型：

- `None` – 无头部。
- `Arrow` – 带有用于在月份/年份之间导航的箭头按钮的头部。
- `Dropdown` – 带有用于在月份/年份之间导航的下拉菜单的头部。

## Chinese mode

如果启用，则日历将使用中文区域设置来表示月份和日期的名称。仅限 LVGL 9.x 及更高版本。
