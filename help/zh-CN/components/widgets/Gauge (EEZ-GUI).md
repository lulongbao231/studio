# DESCRIPTION

在仪表图表中显示通过 `Data` 属性选择的值。另外，如果设置了，它还会在给定位置显示阈值线，例如用来标记某个临界值。

# PROPERTIES

## Data

在 Widget 中显示的 `[Min, Max]` 范围内的值。

## Default style

渲染 Widget 背景时使用的样式。

## Min

`Data` 可以包含的最小值。

## Max

`Data` 可以包含的最大值。

## Threshold

`[Min, Max]` 范围内的可选值，将在其位置用默认样式（`Threshold style`）绘制一条线。

## Unit

将显示在 `Data` 值右侧的单位。

## Bar style

用于渲染 Widget 内部条的样式。

## Value style

用于渲染通过 `Data` 指定的值的样式。

## Ticks style

用于渲染刻度上刻度线的样式。

## Threshold style

用于渲染阈值线的样式。
