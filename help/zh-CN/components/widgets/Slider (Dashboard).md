# DESCRIPTION

此 Widget 允许我们通过移动滑块上的旋钮从列表中选择一个值。

# PROPERTIES

## Data [EMPTY]


## Default style

渲染 Widget 时使用的样式。

## Value

用于存储在 `[Min, Max]` 范围内所选值的变量。

## Min

可以选的最小值。

## Max

可以选的最大值。

## Step

步长是一个数字，它指定了值必须遵循的粒度。

## View min

显示的最小值。

## View max

显示的最大值。

## Enabled

如果为 true，则滑块可用，否则将被禁用。
