# DESCRIPTION

执行一个或多个 LVGL 特定动作。

# PROPERTIES

## Actions

要执行的动作列表。可用的动作如下：

- **切换屏幕**：切换到指定屏幕
  - *屏幕*：要切换到的屏幕
  - *淡入方式*：移动到新页面时的动画选择
  - *速度*：动画时长（毫秒）
  - *延迟*：动画开始前的延迟（毫秒）。
  - *使用堆栈*：将活动屏幕压入堆栈。

- **切换到上一个屏幕**：切换到上一个屏幕
  - *淡入方式*：移动到新页面时的动画选择
  - *速度*：动画时长（毫秒）
  - *延迟*：动画开始前的延迟（毫秒）。

- **创建屏幕**：创建屏幕（应在“设置 - 构建”中启用“屏幕生命周期支持”）
  - *屏幕*：要创建的屏幕

- **删除屏幕**：删除屏幕（应在“设置 - 构建”中启用“屏幕生命周期支持”）
  - *屏幕*：要删除的屏幕

- **屏幕是否已创建**：检查屏幕是否已创建（应在“设置 - 构建”中启用“屏幕生命周期支持”）
  - *屏幕*：屏幕
  - *将结果存入*：用于存储屏幕状态的布尔变量

- **设置对象 X 坐标**：设置对象的 x 坐标
  - *对象*：要设置 x 坐标的对象
  - *X*：要设置的 x 坐标

- **获取对象 X 坐标**：获取对象的 x 坐标
  - *对象*：要获取 x 坐标的对象
  - *将结果存入*：用于存储 x 坐标的变量

- **设置对象 Y 坐标**：设置对象的 y 坐标
  - *对象*：要设置 y 坐标的对象
  - *Y*：要设置的 y 坐标

- **获取对象 Y 坐标**：获取对象的 y 坐标
  - *对象*：要获取 y 坐标的对象
  - *将结果存入*：用于存储 y 坐标的变量

- **获取对象显示 X 坐标**：获取对象相对于显示原点的 x 坐标
  - *对象*：要获取 x 坐标的对象
  - *将结果存入*：用于存储 x 坐标的变量

- **获取对象显示 Y 坐标**：获取对象相对于显示原点的 y 坐标
  - *对象*：要获取 y 坐标的对象
  - *将结果存入*：用于存储 y 坐标的变量

- **设置对象宽度**：设置对象的宽度
  - *对象*：要设置宽度的对象
  - *宽度*：要设置的宽度

- **获取对象宽度**：获取对象的宽度
  - *对象*：要获取宽度的对象
  - *将结果存入*：用于存储宽度的变量

- **设置对象高度**：设置对象的高度
  - *对象*：要设置高度的对象
  - *高度*：要设置的高度

- **获取对象高度**：获取对象的高度
  - *对象*：要获取高度的对象
  - *将结果存入*：用于存储高度的变量

- **设置对象样式属性**：在样式中设置属性的值。
  - *对象*：部件
  - *属性*：要设置的样式属性
  - *值*：要为属性设置的值
  - *部件*：要设置属性的对象部分
  - *状态*：要设置属性的对象状态

- **设置对象不透明度**：设置对象的不透明度
  - *对象*：要设置不透明度的对象
  - *不透明度*：要设置的不透明度 (0-255)

- **获取对象不透明度**：获取对象的不透明度
  - *对象*：要获取不透明度的对象
  - *将结果存入*：用于存储不透明度的变量

- **向对象添加样式**：向对象添加样式
  - *对象*：要添加样式的对象
  - *样式*：要添加的样式

- **从对象移除样式**：从对象移除样式
  - *对象*：要移除样式的对象
  - *样式*：要移除的样式

- **设置对象隐藏标志**：设置对象的隐藏标志
  - *对象*：要设置隐藏标志的对象
  - *隐藏*：隐藏标志值

- **向对象添加标志**：向对象添加标志
  - *对象*：要添加标志的对象
  - *标志*：要添加的标志

  - *对象*：要清除标志的对象
  - *标志*：要清除的标志

- **检查对象是否具有指定标志**：检查对象是否具有指定的标志
  - *对象*：要检查标志的对象
  - *标志*：要检查的标志
  - *将结果存入*：用于存储结果的变量

  - *值*：要设置的值

  - *对象*：圆弧对象
  - *要旋转的对象*：要旋转的对象
  - *偏移*：考虑用此值增大半径（< 0：用于更小的半径）

- **设置条的值**：设置条的值
  - *对象*：要设置值的条
  - *值*：要设置的值 (0-100)
  - *动画*：设置值时使用动画

- **设置按钮矩阵按钮控制**：设置条的值
  - *对象*：要设置值的条
  - *按钮ID*：要修改的按钮的从 0 开始的索引（不计换行）。
  - *控制*：按位或的属性。例如 `LV_BUTTONMATRIX_CTRL.NO_REPEAT | LV_BUTTONMATRIX_CTRL.CHECKABLE`

- **清除按钮矩阵按钮控制**：清除按钮矩阵中按钮的属性
  - *对象*：要设置值的条
  - *按钮ID*：要修改的按钮的从 0 开始的索引（不计换行）。
  - *控制*：按位或的属性。例如 `LV_BUTTONMATRIX_CTRL.NO_REPEAT | LV_BUTTONMATRIX_CTRL.CHECKABLE`

- **设置日历今天日期**：设置今天的日期

  - *年*：当前年份

  - *日*：当前日 [1..31]

  - *年*：高亮的年份
  - *月*：高亮的月份 [1..12]
  - *日*：高亮的日 [1..31]

- **获取日历按下的日期**：获取当前按下的日期
  - *对象*：日历对象
  - *将年份存入*：用于存储年份的整数变量
  - *将月份存入*：用于存储月份的整数变量 (1..12)
  - *将日存入*：用于存储日的整数变量 (1..31)

- **设置下拉框选中项**：设置下拉框的选中项

- **设置图像源**：设置图像的源图像

- **设置图像角度**：设置图像的角度
  - *对象*：要设置角度的图像

- **设置图像缩放**：设置图像的缩放
  - *对象*：要设置缩放的图像
  - *缩放*：要设置的缩放。将系数设为 256 以禁用缩放。较大的值放大图像（例如 512 为两倍大小），较小的值缩小图像（例如 128 为一半大小）。

- **设置键盘文本域**：为键盘设置文本域（textarea）
  - *对象*：要设置文本域（textarea）的键盘
  - *文本域*：要设置的文本域（textarea）

- **设置标签文本**：设置标签的文本

  - *文本*：要设置的文本

- **更新二维码**：设置二维码对象的文本

  - *文本*：要显示的文本

- **设置滚轮选中项**：设置滚轮的选中项
  - *对象*：要设置选中项的滚轮
  - *选中项*：选中项的索引

- **设置滑块值**：设置滑块的值
  - *对象*：要设置值的滑块
  - *值*：要设置的值
  - *动画*：设置值时使用动画

  - *对象*：要设置值的滑块
  - *左侧值*：要设置的左侧值
  - *动画*：设置值时使用动画

  - *对象*：要获取活动选项卡的选项卡视图
  - *将结果存入*：用于存储活动选项卡索引的变量

  - *将结果存入*：用于存储聚焦对象的变量

  - *组*：要冻结/解冻聚焦的组

- **设置组循环**：设置焦点 next/prev 是否允许从第一个对象循环到最后一个对象，或反向循环。

- **设置组编辑模式**：手动设置当前模式（编辑或导航）。
  - *组*：要设置编辑模式的组
