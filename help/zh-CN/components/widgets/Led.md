# DESCRIPTION

LED 是类似矩形（或圆形）的对象，其亮度可以调节。亮度越低，LED 的颜色越暗。

[更多信息](https://docs.lvgl.io/master/widgets/led.html)

# PROPERTIES

## Color

你可以设置 LED 的颜色。此颜色将用作背景色、边框色和阴影色。

## Color type

这里我们可以选择 `Color` 属性是否将由表达式计算。

## Brightness

LED 的亮度。亮度应在 0（最暗）到 255（最亮）之间。

## Brightness type

这里我们可以选择 `Brightness` 属性是否将由表达式计算。
