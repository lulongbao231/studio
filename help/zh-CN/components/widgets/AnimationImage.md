# DESCRIPTION

动画图像与普通的 'Image'（图像）对象类似。唯一的区别是，你设置的不是一张源图像，而是一个由多张源图像组成的数组。

你可以指定持续时间和重复次数。

[更多信息](https://docs.lvgl.io/master/widgets/animimg.html)

# PROPERTIES

## Images

要制作动画的图像列表。

## Duration

动画的持续时间，以毫秒为单位。

## Repeat infinite

如果启用，则动画将无限次重复。

## Repeat count

如果禁用“Repeat infinite”（无限重复），则使用此属性控制动画重复的次数。
