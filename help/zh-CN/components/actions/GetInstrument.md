# DESCRIPTION

按其 ID 获取仪器对象。仪器 ID 可以在以下两个位置找到：在 `Instruments` 主页面上选择仪器时的仪器 `Properties`，以及仪器 `Terminal` 选项卡的标题中。

![Alt text](../images/get_instrument_id1.png)

![Alt text](../images/get_instrument_id2.png)

当您想要访问特定仪器时使用此 Action，即您不想使用对话框作为选择仪器的方法。

# PROPERTIES

## Instrument ID

我们要获取其对象的仪器的 ID。

# INPUTS

## seqin

一个标准顺序输入。

# OUTPUTS

## seqout

一个标准顺序输出。

## instrument

获取的对象被发送到此输出。
