# DESCRIPTION

用于显示单行文本的 Widget。

# PROPERTIES

## Text

要显示的文本。这是一个表达式，如果只想显示某些静态文本，则应将该文本用引号括起来输入。如果表达式使用了变量，则该表达式无法在编辑器中计算，因此将显示表达式本身而不是文本。

## Default style

用于渲染 Widget 的样式。

## Name

如果用于 `Text` 属性的表达式在编辑期间无法计算，则可以在此设置编辑器中显示的文本。此外，此文本还会显示在 _Widgets Structure_（部件结构）面板中。

## Focused style
