# DESCRIPTION

如果在 Page 或 User Widget 内使用此 Action，则它将把动画时间线的位置以给定速度（`Speed` 属性）从某一位置（`From` 属性）移动到另一位置（`To` 属性）。

如果我们想要立即跳转到某个位置（`To` 属性），则应将 `Speed` 设置为 `0` - 在这种情况下，`From` 属性的值无关紧要（它可以设置为与 `To` 属性相同的值）。

表达式 `Flow.pageTimelinePosition()` 可用于 `From` 属性，在这种情况下，动画将从当前位置开始。

# PROPERTIES

## From

以秒为单位的起始位置。

## To

以秒为单位的结束位置。

## Speed

确定动画的持续时间。如果设置为 `1`，则动画将持续 `From - To` 秒。如果我们想要快两倍的动画，则应设置为 `2`；如果我们想要慢两倍的动画，则应设置为 `0.5`。

如果我们希望动画持续特定时间 `T`，则可以使用公式 `T / (From - To)`，例如，如果 `T` 等于 `0.5` 秒，`From` 为 `1` 秒，`To` 为 `3` 秒，则速度应设置为 `0.5 / (3 - 1)`，即 `0.25`。

如果设置为 `0`，则执行期间将立即跳转到 `To` 位置。

# INPUTS

## seqin

一个标准顺序输入。

# OUTPUTS

## seqout

一个标准顺序输出。当动画完成时，即到达 `To` 位置时，该输出将被激活。
