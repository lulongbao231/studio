# DESCRIPTION

此 Widget 用于显示位图。

# PROPERTIES

## Data

要显示的位图的索引。有必要使用函数 `Flow.getBitmapIndex({<bitmapName>})`，该函数接收 `bitmapName`（即位图的名称）并返回位图的索引。通过这种方式，我们可以选择或更改运行时将显示的位图，因为例如 `bitmapName'` 可以来自某个变量。

## Default style

渲染 Widget 背景时使用的样式。

## Bitmap

要显示的位图的名称。
