# DESCRIPTION

此 Widget 允许与仪器进行交互。它由几个部分组成，其中一些部分可以通过相关属性隐藏。

![alt text](../images/scpi_terminal.png)

# PROPERTIES

## Instrument

选中的仪器对象。

## Show connection status bar

显示/隐藏仪器连接状态栏。

## Show shortcuts

显示/隐藏快捷方式面板。

## Show help

显示/隐藏命令帮助面板。

## Show side bar

显示/隐藏带有历史记录搜索选项的侧边栏。
