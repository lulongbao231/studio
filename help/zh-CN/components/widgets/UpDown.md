# DESCRIPTION

此 Widget 允许我们使用递减和递增按钮选择一个值。

# PROPERTIES

## Data

用于存储在 `[Min, Max]` 范围内所选值的变量。

## Default style

渲染 Widget 背景和文本时使用的样式。

## Down button text

为递减值而显示在按钮内部的文本。

## Up button text

为递增值而显示在按钮内部的文本。

## Min

可以选的最小值。

## Max

可以选的最大值。

## Buttons style

用于渲染按钮的样式。
