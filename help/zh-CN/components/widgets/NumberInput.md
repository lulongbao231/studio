# DESCRIPTION

当我们想要输入一个数字时，使用此 Widget。

# PROPERTIES

## Default style

渲染 Widget 时使用的样式。

## Value

用于存储所输入数字的变量。

## Min

可以输入的最小值。

## Max

可以输入的最大值。

## Step

步长是一个数字，它指定了值必须遵循的粒度。

## Disable default tab handling

如果要在该 Widget 获得焦点时禁用默认的 TAB 键处理，请将其设置为 false。
