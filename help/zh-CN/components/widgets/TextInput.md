# DESCRIPTION

当我们想要输入文本时，使用此 Widget。

# PROPERTIES

## Value

用于存储所输入文本的变量。

## Default style

渲染 Widget 时使用的样式。

## Read only

如果希望此 Widget 为只读，即禁用用户输入，请设置为 `true`。

## Placehoder

尚未输入任何内容时，在起始位置显示的文本。

## Password

如果输入的是密码，则应启用此属性，这样输入密码时显示的是 `*` 而不是字符。
