# DESCRIPTION

`Imgbutton`（图像按钮）与简单的 `Button` Widget 非常相似。唯一区别是，它在每种状态下显示用户定义的图像，而不是绘制矩形。

[更多信息](https://docs.lvgl.io/8.3/widgets/extra/imgbtn.html)

# PROPERTIES

## Released image

`Released`（释放）状态的图像。

## Pressed image

`Pressed`（按下）状态的图像。

## Disabled image

`Disabled`（禁用）状态的图像。

## Checked released image

Widget 同时处于 `Checked` 和 `Disabled` 状态时的图像。

## Checked pressed image

Widget 同时处于 `Checked` 和 `Pressed` 状态时的图像。

## Checked disabled image

Widget 同时处于 `Checked` 和 `Disabled` 状态时的图像。
