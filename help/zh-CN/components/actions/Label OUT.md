# DESCRIPTION

此动作用于结合 `Label IN` 动作使用。进入 `Label OUT` 的所有线都将在同一 Flow（即 _Page_ 或 _User_ Action）内通过具有相同标签名称的 `Label IN` 输出。因此，不允许从一个 Flow"跳转"到另一个 Flow。可以有多个 `Label OUT`，但只能有一个具有相同标签名称的 `Label IN`。

# PROPERTIES

## Label

连接 `Label IN` 和 `Label OUT` 动作的标签名称。

# INPUTS

## seqin

一个标准顺序输入。
