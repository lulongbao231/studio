# DESCRIPTION

在给定的纠错级别下，渲染表示给定文本字符串的二维码。

# PROPERTIES

## Text

为其生成二维码的文本。

## Default style

渲染 Widget 时使用的样式。

## Error correction

二维码符号中的纠错级别，可选选项如下：

-   `Low` – 二维码大约可以容忍 7% 的错误码字。
-   `Medium` – 二维码大约可以容忍 15% 的错误码字。
-   `Quartile` – 二维码大约可以容忍 25% 的错误码字。
-   `High` – 二维码大约可以容忍 30% 的错误码字。
