# DESCRIPTION

在仪表图表中显示通过 `Data` 属性选择的值。

# PROPERTIES

## Data

在 Widget 中显示的 `[Min, Max]` 范围内的值。

## Default style

渲染 Widget 背景时使用的样式。

## Title

显示在仪表图表上方的名称。

## Min range

`Data` 可以包含的最小值。

## Max range

`Data` 可以包含的最大值。

## Color

图表内弧形条的颜色。

![Alt text](../images/gauge_arc_bar_color.png)

## Margin

在 Widget 边框与图表本身之间手动选择的边距值。
