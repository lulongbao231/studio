# DESCRIPTION

一个可以处于两种状态的按钮：`Default`（默认）或 `Checked`（选中）。

# PROPERTIES

## Data

如果此属性的值为 `false`，则按钮处于 `Default` 状态；如果值为 `true`，则处于 `Checked` 状态。

## Default style

Widget 处于 `Default` 状态时用于渲染的样式。

## Text1

Widget 处于 `Default` 状态时显示的文本。

## Text2

Widget 处于 `Checked` 状态时显示的文本。

## Checked style

Widget 处于 `Checked` 状态时用于渲染的样式。
