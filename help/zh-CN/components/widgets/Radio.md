# DESCRIPTION

`Radio`（单选按钮）Widget 用于单选组中——单选组是描述一组相关选项的单选按钮集合。在给定组中，同时只能选中一个单选按钮。在组中，每个单选按钮具有不同的 `Value` 属性和相同的 `Group variable` 属性。

# PROPERTIES

## Data [EMPTY]


## Default style

渲染 Widget 时使用的样式。

## Label

显示在单选按钮 Widget 旁边的标签。

## Group variable

当此单选按钮 Widget 被选中时，在其中存储来自 `Value` 属性的值的变量。

## Value

当此单选按钮 Widget 被选中时，将存储在 `Group variable` 中的值。此外，通过将该值与 `Group variable` 比较，可以决定此单选按钮 Widget 是否被选中。

## Enabled

如果为 true，则单选按钮可用，否则将被禁用。
