# DESCRIPTION

例如，当我们想要显示某个操作的执行进度时，可以使用此 Widget。

# PROPERTIES

## Data

一个从 Min（进度为 0%）到 Max（进度为 100%）的值。

## Default style

渲染 Widget 时使用的样式。

## Min

`Data` 可以包含的最小值。

## Max

`Data` 可以包含的最大值。

## Orientation

`Progress` Widget 可以有两种方向：

-   水平

-   垂直

    ![Alt text](../images/progress_vert.png)
