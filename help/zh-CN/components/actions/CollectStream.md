# DESCRIPTION

将流连接（拼接）成字符串。由于流中的数据以块到达，因此它们被拼接成一个字符串并发送到数据输出。在流的生命周期内，此 Action 可以多次通过 `data` 发送当前已收集的字符串。当流关闭时，Flow 执行将通过 `seqout` 输出继续。

# PROPERTIES

## Stream

其内容将被拼接成字符串的流。

# INPUTS

## seqin

一个标准顺序输入。

# OUTPUTS

## seqout

一个标准顺序输出。流关闭后，Flow 执行将在此输出处继续。

## data

拼接后的字符串通过此输出发送。
在流的生命周期内，可以多次发送字符串，每次发送的字符串都将包含迄今为止收集的所有数据（即随着新数据的到达，字符串会随时间增长）。
