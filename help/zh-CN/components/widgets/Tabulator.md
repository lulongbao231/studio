# DESCRIPTION

用于显示或编辑表格的 Widget。在底层使用 [Tabulator](https://tabulator.info/)。

# PROPERTIES

## Data

表格数据，更多信息请参见 [Load Data From Array/JSON](https://tabulator.info/docs/6.2/data#array)。

## Basic options

基本表格选项。更多信息请参见 [Tabulator 文档](https://tabulator.info/docs/6.2/options)。

## Advanced options

覆盖基本选项的高级选项，可以通过 JSON 值指定。由于这是表达式属性，你可以在运行时按条件更改选项。

## Persistent configuration

输入用于存储[持久化配置](https://tabulator.info/docs/6.2/options#persistence)的变量。
