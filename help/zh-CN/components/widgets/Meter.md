# DESCRIPTION

`Meter`（仪表）Widget 可以非常灵活地可视化数据。它可以显示弧线、指针、刻度线和标签。

[更多信息](https://docs.lvgl.io/8.3/widgets/extra/meter.html)

# PROPERTIES

## Scales

刻度定义列表。刻度具有小刻度和大刻度以及大刻度上的标签。每个刻度上可以添加一个或多个指示器。有四种不同类型的指示器：

-   Needle image（指针图像）
-   Needle line（指针线条）
-   Scale lines（刻度线）
-   Arc（弧线）
