# DESCRIPTION

此 Action 必须在成功连接到 MQTT 服务器后立即执行，对于每个我们想要订阅的主题都要执行一次。如果服务器针对此主题发布了报文，我们将通过 _MQTTEvent_ Action 的 Message 事件收到相关信息。

# PROPERTIES

## Connection

MQTT 服务器连接的名称。

## Topic

我们想要订阅的主题名称。订阅可以是显式主题，在这种情况下只会收到该主题的消息，也可以包含通配符。有两个可用的通配符：`+` 或 `#`。`+` 可以用作单个层级级别的通配符。它可以与上面的主题一起使用，以获取所有计算机和硬盘的信息，如下所示：

`sensors/+/temperature/+`

作为另一个示例，对于 `a/b/c/d` 这样的主题，以下示例订阅将匹配：

```
a/b/c/d
+/b/c/d
a/+/c/d
a/+/+/d
+/+/+/+
```

以下订阅将不匹配：

```
a/b/c
b/+/c/d
+/+/+
```

`#` 可以用作所有剩余层级级别的通配符。这意味着它必须是订阅中的最后一个字符。对于 `a/b/c/d` 这样的主题，以下示例订阅将匹配：

```
a/b/c/d
#
a/#
a/b/#
a/b/c/#
+/b/c/#
```
